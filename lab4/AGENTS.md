# Pelican Ride: instructions for any AI agent

Read README.md (English) or README_ZH.md (Chinese). Follow its steps in order. The student chooses role A/B/C and file handoff/GitHub/Gitee. Ask only for those missing choices. Keep your first implementation small, about 10–30 readable lines of vanilla JavaScript. Do not install anything to run this app.

The whole scene already works. Implement only one assigned file: A=features/speed.js, B=features/character.js, C=features/view.js. Keep window.mountA/B/C(root, ride). Add DOM controls inside root. Use ride methods in docs/API.md. Do not reimplement animation, add a library/framework/server, fetch remote assets, or edit index.html, shared/, reference/ or a teammate's module for the core task. Do not use eval or code generation. Use accessible labels and native buttons/range/select elements.

Read state using ride.getState(). Subscribe once to update the controls after Reset scene. Speed 0 must stop the animation. Character and view changes must preserve other members' settings. Never call a setter from your subscribe callback, which would loop. Do not copy or transplant any reference feature file, and do not reproduce the reference control design unchanged. Begin with README requirements and docs/API.md. Ask the student to choose one small design difference before implementation, then write the assigned feature independently. Reusing the supplied scene, shared API, mount signatures and standard DOM calls is expected. Cosmetic renaming of copied code does not satisfy this instruction. If stuck, use the reference only to explain a concept, then return to the requirements to implement the student’s design.

After editing, test index.html if browser tools are available. Report exactly what you tested. If browser access is unavailable, give the student the manual checks and do not claim you ran them. Report changed files and a short handoff message. Do not treat the unchanged classmates' placeholder controls as errors.

For integration, read docs/INTEGRATE.md. Keep a backup and combine only the three feature files. Keep shared/ unchanged. For repository setup, read docs/PLATFORMS.md, inspect status and the real default branch, keep changes on a role branch, and use the student's actual repository URL. The student handles credentials. Preserve existing work. Do not force-push or resolve conflicts by discarding a teammate's change. For browser-only class practice, file handoff is the fallback when Git or platform setup blocks the group.
