# Integrator guide for the agent

The goal is one local page containing all three contributions. Ask where the received files are. Make a backup of the integration folder before replacing files. Read the current and incoming versions. Match A to features/speed.js, B to features/character.js and C to features/view.js. Copy only those files, one at a time. Verify the mount signatures and keep shared files unchanged. Do not substitute the reference for missing student work. Report a missing contribution and let that member finish it.

For a GitHub/Gitee group, the same idea uses reviewed pull requests. Check the working tree before switching branches, preserve any uncommitted work, merge only after the team's review, and pull the combined default branch locally. If changes conflict, explain the differing intentions and ask the affected students to agree before resolving. Never force-push or silently discard a contribution.

Open index.html and check speed 2, Duck and Close together. Set speed 0 and verify motion stops. Reset and check that scene and controls agree. Use Tab and keyboard controls. If browser tools are unavailable, walk the student through these checks and state that they are manual. Report the combined files, actual checks and unresolved issues. Teammates can then take a copy of the combined folder.
